02・做得到

做得到

先關訓練開關，再寫指示

  1. 1-1先關訓練開關，再開始聊

    1. ChatGPT：左下角頭像 → 設定 → 資料控管，把「改善模型以惠及所有人」（英文 Improve the model for everyone）關掉。
    2. Claude：左下角名字縮寫 → 設定 → 隱私，把「協助改善 Claude」（英文 Help improve Claude）關掉。這個開關也管 Claude Code 的工作。
    3. Gemini：Google 的活動記錄設定（說明頁叫 Keep Activity，舊名 Gemini Apps Activity）⚠️ 位置以畫面為準。關掉後，從雲端硬碟加檔案到 Gem 這類功能可能不能用，依你的需求決定。
    4. 研究用的對話不要按讚或倒讚：以 Claude 為例，按了之後那次回饋連同對話內容會另外保存 5 年。

    你應該看到：兩個開關都顯示為關閉。

    個人帳號不論免費或付費，預設都可能拿對話改進模型。學校買的 Business、Enterprise、Edu 方案預設不拿；用學校信箱自己註冊的個人帳號不算。

    完成判準：開關是關的，或者你清楚知道自己為什麼開著。

  2. 1-2寫自訂指示：讓它每次都知道你是誰

    1. 到下面「用得上」複製「自訂指示範本」，貼到記事本，把大括號換成你的領域、身分、題目（一句話）和方法。
    2. ChatGPT：設定 → 個人化 → 自訂指示（Custom instructions），先確認「啟用自訂」是開的，再貼上、儲存。
    3. Claude：設定 → 一般 → 給 Claude 的指示（Instructions for Claude，舊版叫「個人偏好」），貼上同一段。
    4. Gemini：可以在設定裡的「已儲存的資訊」寫背景 ⚠️，或等 1-5 把這段放進 Gem 的指示。
    5. 每一家都開一個新對話，問：「你知道我是做什麼研究的嗎？」

    你應該看到：它答得出你的研究主題，回答用的是台灣用語。

    卡住了：答不出來：回設定確認有儲存、「啟用自訂」是開的，然後開新的對話再問一次。

    題目寫太大（例如「AI 與教育」），AI 只能給很泛的回答；縮到一句話講得完。

    完成判準：開新對話問「你知道我是做什麼研究的嗎？」，它答得出你的研究主題。

  3. 1-3看一眼記憶開關

    1. ChatGPT：設定 → 個人化 → 記憶，有「參照已儲存的記憶」和「參照聊天紀錄」兩個開關。關前者會連後者一起關。
    2. ChatGPT 已儲存的記憶要到「管理記憶」刪；刪對話不會刪記憶。
    3. ChatGPT 只想問一次、不留紀錄：用「暫存對話」。沒按儲存之前不留紀錄、不建記憶、不拿去訓練；OpenAI 仍可能為了安全保留最多 30 天。
    4. Claude：設定 → 記憶（舊版在「功能」頁）。免費、Pro、Max 的記憶預設是開的。
    5. Claude 某一次不想用記憶：送出第一句之前，在輸入框的「＋」選單把記憶關掉；或用右上幽靈圖示的「無痕對話」（仍保留 30 天，專案裡不能用）。

    你應該看到：你說得出每一家的記憶現在是開還是關。

    暫存對話、無痕對話都不是放個資的地方。

    完成判準：說得出自己的記憶現在是開還是關。

  4. 1-4開一個研究專案

    1. 先決定要放什麼：研究問題、關鍵詞表、計畫摘要、已發表文獻。拿不準能不能上傳，今天就只放已發表文獻。
    2. ChatGPT：左側欄 新專案 → 取名（例如你的論文題目）→ 上傳幾篇文獻。
    3. ChatGPT：專案右上 ⋯ → 專案設定，貼上「專案指示範本」。專案指示只對這個專案有效，會蓋過全域的自訂指示。
    4. Claude：左側欄 專案 → 新增專案 → 取名 → 把文獻上傳到知識區 → 按「設定專案指示」，貼上同一段。
    5. 在專案裡問一個檔案查得到的問題，例如「第一篇文獻的研究對象是誰？」，再打開原文對照。

    你應該看到：答案標出是哪個檔案、哪一段，而且原文對得上。

    卡住了：上傳不了：檢查檔案數量上限。ChatGPT 每個專案免費 5 個檔、Go 和 Plus 25 個；Claude 免費帳號最多 5 個專案。

    放進專案的檔案會送到 AI 公司的伺服器。受訪者資料、未發表資料、別人寄給你看的稿子都不放。

    完成判準：在專案裡問一個檔案查得到的問題，再打開原文，確認答案對得上。

  5. 1-5做三個快捷指令

    1. 到下面「用得上」把「;摘要」「;批判」「;改寫」三段準備好。
    2. Gemini Gem：打開 gemini.google.com → 左側「探索 Gem」（Explore Gems）→「新增 Gem」（New Gem）→ 名稱打「論文摘要」→ 指示貼「;摘要」那段 → 儲存。另兩段各做一個 Gem。
    3. Windows：設定 → 系統 → 剪貼簿，打開「剪貼簿歷程記錄」→ 把三段各複製一次 → 按 Win＋V → 點每一段旁邊的圖釘（或 ⋯ → 釘選）。
    4. Mac：蘋果選單 → 系統設定 → 鍵盤 → 文字替代（在「文字輸入」那一區）→ 按「＋」→ 左欄打 ;摘要、右欄貼整段 → 完成。另兩段照做。
    5. Windows 測試：在任何輸入框按 Win＋V，點剛剛釘選的那段，整段貼上。
    6. Mac 測試：在任何輸入框打「;摘要」，再按空白鍵，看整段有沒有展開。

    你應該看到：一個動作就叫出整段 prompt。

    卡住了：Mac 的文字替代在部分程式不會自動展開 ⚠️，那就改用 Gem，或從備忘錄複製貼上。

    前面加分號是為了避免平常打字時誤觸發。作業系統這兩招在每一家 AI 都能用。

    完成判準：三個快捷指令都叫得出來。

  6. 1-6A/B 測試：設定真的有效嗎？

    1. A（沒設定）：在 ChatGPT 開「暫存對話」，開始前把「套用自訂指示」與記憶都關掉。
    2. B（有設定）：在你的研究專案裡開一個新對話。
    3. 兩邊都問同一句：「請推薦 3 篇我這個主題的重要文獻」。
    4. 比三件事：有沒有附 DOI、有沒有標出不確定、用語是不是台灣用語。各寫「有／沒有」。
    5. 把兩邊給的文獻整段複製，存到一個文件，取名「Day 2 要驗的文獻」。

    你應該看到：一張 2×3 的小表（A、B × 三件事）和一份文獻清單。

    兩邊差不多也是結果，照實記下來。

    完成判準：寫得出一句觀察，並把 AI 給的 3 篇文獻存起來，Day 2 要驗。
做完勾一勾（6 項全勾，解鎖技能卡 02）
03・用得上

用得上

範本照抄，換成你的研究

大括號 { } 換成你自己的內容。複製任何一段，就解鎖技能卡 03。今天練習請用公開文獻或範例資料，不要貼真的受試者資料。

打開 ChatGPT ↗打開 Claude ↗打開 Gemini ↗

自訂指示範本（研究者版）

我是{領域}的{碩士生／博士生／教師}，研究主題是{一句話}，常用方法是{問卷／訪談／實驗}。請用繁體中文、台灣用語回答。
1. 引用文獻一定附 DOI 或網址；沒有把握就說「我不確定」，不要編造文獻。
2. 專有名詞與統計名詞第一次出現時，附上英文原文。
3. 先給結論，再說理由；你的推論前面標【推論】。
4. 如果我貼上的內容有受試者、受訪者或學生的真實個資（姓名、學號、電話、地址），先提醒我刪掉，不要繼續分析。

專案指示範本

這個專案是{研究題目}。研究問題：{一句話}。關鍵詞：{中文}／{英文}。目前進度：{例如：正在寫文獻探討}。
回答時只根據專案裡的檔案；檔案裡找不到的，直接說找不到，不要用一般知識補。引用時標出是哪一個檔案、哪一頁或哪一段。

快捷指令 ;摘要

用 5 點摘要這篇論文：研究問題、方法、樣本、主要發現、限制。每一點標出原文頁碼；原文沒寫的那一點寫「未提及」，不要推測。

快捷指令 ;批判

請用嚴格審稿人的角度讀下面這段。列出論證最弱的 3 個地方，每一個說明為什麼弱，再給一個可以補強的方向。不要改寫我的文字。

快捷指令 ;改寫

把下面這段改成學術寫作語氣。保留原意；不新增、不刪除、不移動任何引用；不加入新的事實或文獻。改完用條列說明你改了哪些地方。

05・守得住

守得住

設定再好，這三條都要自己守

一

先關訓練，再開始聊

個人帳號預設都可能拿對話改進模型。在開始聊研究之前就關，關了紀錄照樣留著。

二

個資在貼上之前就拿掉

自訂指示第 4 條只是最後一道提醒：AI 看到的那一刻，資料已經送出去了。

三

設定不是保證

設定只能降低編造的機率。AI 給的每一篇文獻，Day 2 起都要回查。

三條線說得出來，也知道為什麼。
